NOVA Market Ecommerce Demo — Full Project

Files:
- index.html: complete ecommerce demo with the Yantra support widget snippet.
- README.txt: this file.

How to run:
1. Extract this ZIP.
2. Open index.html in a browser, or use VS Code Live Server.
3. Ensure the Yantra Ticketing Agent is enabled and the API key/domain configuration is valid if the support widget does not appear.

The project is a static HTML demo; no build step is required.
